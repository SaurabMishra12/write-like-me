# Repository guidance

Preserve original drafts and personal provenance. Read SKILL.md for writing operations. Python tools are local diagnostics, not semantic truth or authorship detectors. Keep private/ out of exports. Permanent-profile updates require a diff and explicit user approval.

For code discovery prefer the configured codebase-memory MCP graph, validate index coverage for material paths, and inspect exact source when stale/unindexed. Run python -m pytest before claiming a tool change works. Add meaningful regression cases for factual drift, privacy or behavior changes. Do not turn constructed examples into personal voice evidence.
