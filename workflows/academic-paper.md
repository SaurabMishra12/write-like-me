# Academic research paper

Load academic-profile.yaml and shared profiles. Preserve the existing section and LaTeX structure unless reorganization was requested.

1. Identify the actual research question, audience, main claim, evidence and inferential scope. Label completed experiments, planned experiments, hypotheses and unknowns separately.
2. Extract a ledger for each paragraph: claim, reason, evidence, warrant, limitation/response. Require a real source for a literature claim. An unsupported gap or novelty statement is an unresolved issue, not an opportunity to invent one.
3. Lock every number with its metric and denominator, names/dates, citations/BibTeX keys, bibliography, units, equations/macros/environments, code, algorithmic complexity and conclusions. Add exact custom locks for uncommon notation and technical terms.
4. Make one coherent revision. Define unfamiliar objects before manipulating them; connect concrete mechanism to symbols. Preserve necessary technical detail and deliberate passive constructions. Remove only redundant wrappers or repeated argument. Never casualize the paper or change the certainty of a claim.
5. Run the factual guardian and inspect a unified diff. A detected lock violation vetoes the candidate. Even with unchanged spans, review quantifiers, comparisons, attribution, causal wording and citation-claim alignment. Record unresolved semantic concerns; return them with the proposed edit.

Acceptance: every retained result maps to evidence, every equation/citation remains intact, claims have bounded scope, and the argument remains the user's. Never report “scientifically verified” from surface checks.

Example failure test: unchanged scores with a revised sentence that swaps which method won. Exact numbers can match; semantic review must reject the swapped attribution.
