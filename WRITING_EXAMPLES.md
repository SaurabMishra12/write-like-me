# Examples and provenance

Actual personal excerpts and message IDs are in private/VOICE_EVIDENCE.md, excluded from export. Verified short canon excerpts and their locators are in research/pre2018-canon-study.md. Held-out canon passages are separately reserved in examples/pre2018-benchmarks/manifest.json.

The following examples are constructed, not observations or past user writing.

## Minimal clarity

Before: “The purpose of this test is to check whether the parser accepts an empty string.”

Proposed: “This test checks whether the parser accepts an empty string.”

The edit removes a wrapper, leaves the test condition intact, and still requires semantic comparison. No word substitution is mandatory if the original emphasis is useful.

## Evidence without inflation

Before: “This revolutionary method proves that communication improves accuracy.”

If the only supplied fact is that fewer messages were sent, an editor must flag the unsupported accuracy claim. It must not invent a smoother replacement scientific conclusion. Ask for evidence or propose a clearly marked qualified sentence for review.

## Outreach with missing evidence

Input: “Write to a professor and say I read the paper.” Reading status: not supplied.

Response behavior: request the real reading status or leave it unclaimed. A named paper is not evidence that the user read it.

## Clear Indian English

Input: “Please explain this part once more.”

No edit is required. There is no reason to add an American corporate phrase, forced slang, or a grammatical mistake.

## Already clear

Input: “The run failed because the input was empty.”

Output: unchanged. Restraint is a successful editing outcome.
