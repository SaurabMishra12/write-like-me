# Style confidence report

Evidence is small and genre-limited: six profile messages, four eligible English prompts, three profile source groups. The English subset contains 189 whitespace-delimited words. Do not present these as hundreds of independent sentences. There are two calibration messages in another group and one held-out message in a fifth group. The profile was frozen before comparative generation.

High confidence: the user's explicit requirements (factual integrity, no invented experiences, no detector evasion, preserve clear Indian English, minimal useful edits). These are declared preferences, not statistical discoveries.

Medium confidence: task-oriented directness and requests for connected detail within informal task prompts. Low confidence: stable long-form rhythm, sentence complexity, question rate, passive-voice rate, paragraph architecture, formal email cadence, LinkedIn tone, or exact Hindi syntactic influence. Speech-to-text artifacts and typos are not modeled as deliberate preferences.

Sentence-length metrics from the analyzer are descriptive only. Sparse punctuation can make a long prompt count as one segment; punctuation-normalizing it would create synthetic observations. No target sentence length or burstiness quota is imposed. Active/passive classification and subordinate-clause parsing are not implemented as reliable automatic measurements; qualitative review must be marked as such.

Canon confidence depends on the inspected passage and date verification, not the author's reputation. Metadata-only sources cannot support detailed style analysis. Later-hosted reprints must identify original dates, and old generated samples remain excluded. Coverage and gaps for every required author appear in the canon report.

No blind human voice ratings, user preference scores, model training, cross-platform execution, or causal claim of superior writing quality is established by software regression tests. New confirmed samples should fill real genre gaps. Add them to a separate source group, rerun corpus validation, inspect a proposed profile diff, and approve before replacement.
